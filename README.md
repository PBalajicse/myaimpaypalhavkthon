# PayPal AI Payment Assistant

A Java Spring Boot web application that combines an AI chat assistant with PayPal Sandbox payment functionality.

## Features

- AI chat interface
- PayPal Sandbox order creation
- Order status dashboard
- Java Spring Boot backend
- H2 in-memory database

## How to Run

1. Install Java 17 or later.
2. Install Maven.
3. Open the project in Eclipse or IntelliJ.
4. Add your PayPal Sandbox Client ID and Secret in `src/main/resources/application.properties`.
5. Run `MyaimprojectApplication`.
6. Open http://localhost:8081

## PayPal Sandbox

This project uses PayPal Sandbox for testing. No real money is transferred during Sandbox testing.
